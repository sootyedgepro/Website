Before submitting

Run the two minute support preflight.

Account name mismatches and missing details can delay access. Complete these checks before opening a request.

  1. 01Confirm you are signed into the exact TradingView account submitted during onboarding.
  2. 02Copy the TradingView username exactly, including capitalization and punctuation.
  3. 03Refresh TradingView and check private scripts before reporting missing access.
  4. 04Record the indicator name, symbol, market, and chart timeframe where the issue appears.
  5. 05Capture a screenshot of the full screen that includes the chart and any visible error message.
  6. 06List the troubleshooting steps you have already completed.
