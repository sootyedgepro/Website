# Journey Lanyard interaction audit — November 8, 2026

## Preserved composition

The existing actual React Bits JavaScript + CSS Lanyard remains mounted by `shared/funnel-lanyards.jsx`. The full story-grid canvas is pointer-transparent and raycasts input delegated from `#journey`. The scene stays at its existing dimensions, anchor, strap, card finish and orange colors. The existing depth toggle still switches the stage between z-index 0 and 3. This audit changes no layout or visual settings in `funnel-lanyards.css`.

## Narrow interaction/lifecycle fixes

- `shared/vendor/react-bits/Lanyard.jsx` now uses a shared control-target guard for both pointerdown and touchstart. Buttons, links, form controls, labels, semantic buttons/links and editable content retain native behavior even where their coordinates overlap the rendered card.
- Touchstart calls preventDefault only for a raycast card hit and a cancelable event.
- Captured pointer identity is tracked, so another finger cannot replace or steer an active drag. Pointerup, pointercancel and lostpointercapture release the grab; only a short actual pointerup can flip the card.
- Leaving the delegated input section clears an idle hover cursor. Cleanup releases any remaining pointer capture and restores the prior inline cursor when it still owns that cursor value.
- The renderer effect depends on `interactionRoot`, so changing the delegated selector removes listeners from the prior element before attaching to the next.
- `JourneyBadge` guards the reverse-texture font-ready promise against unmount. Its existing front-texture promise already had an active flag.

Existing renderer frame cancellation, resize/intersection observer disconnection, event-listener removal, and WebGL geometry/material/texture disposal remain. Reduced motion continues to use the static badge and keyboard-accessible flip button in the wrapper.

## Verification

This is a focused source audit. The lanyard adapter was bundled with esbuild in memory after the fixes; no layout CSS was changed. Root-agent runtime checks of card dragging, ordinary buttons/links, depth toggle, touch scrolling and flip behavior remain separate from this source validation.
