## Result

- Gold CTAs use a single 12-second StarBorder light, matching gold trail, a low-contrast gold gradient and fine grain. The class-takeaway CTA retains its actual SpecularButton with matching gold lighting. All existing anchor attributes and destinations are preserved.
- The travel section has a dark, full-width photographic stage, with natural photo proportions, no arrow control strip and no view-all panel. The component's own caption and count remain.
- Wheel input browses the row. The optional `hoverSpeed` extension moves at up to 54 CSS pixels per second only near the outer quarter of the stage. The middle stays still. Pointer leave, keyboard input, dragging, an open photo, document hiding and motion pause stop the drift.
- Original click-to-center/open, Enter/Space open, Escape close, arrow/Home/End navigation and touch swipe remain. Vertical touch gestures continue to scroll the page (`touch-action: pan-y`). There is no additional modal or second click listener over the component.
- The WebGL-unavailable fallback is a native horizontally scrollable photo row with links to the original images.

## Local source adaptation and checks

The copied FlexCarousel now accepts optional `hoverSpeed` (default 0), `paused` (default false), and `ariaLabel` props. Defaults retain upstream behavior. Runtime reduced-motion changes are observed and cleaned up; quiet mode stops autonomous movement and resolves explicit navigation/zoom without animated settling. Hidden/offscreen frames stop scheduling. The existing cleanup still cancels its frame, disconnects observers, removes pointer/wheel/keyboard/visibility listeners, disposes image slots, and loses the WebGL context; the new media listener is removed too.

The two JSX files and CSS parsed through the installed esbuild with zero warnings. Source checks confirmed ribbon settings, arrow buttons and view-all controls are absent; original photo extraction, 12-second light timing, hover motion settings and touch vertical pan remain.
